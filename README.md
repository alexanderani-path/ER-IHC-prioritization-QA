# ER-IHC-prioritization-QA

**An H&E-Based Deep Learning Framework for ER IHC Prioritization and Quality Assurance in Breast Cancer**

Mohammad Alexanderani, Hooman Rashidi, Liron Pantanowitz, Nam Tran, Matthew Hanna
Computational Pathology & AI Center of Excellence (CPACE), University of Pittsburgh / UPMC

## Overview
A single H&E-derived score supports the estrogen receptor (ER) immunohistochemistry (IHC) workflow at two points while IHC remains the test of record for every patient:

1. **Prioritization (triage):** each case is scored when the H&E slide is scanned, so the IHC worklist can be ordered with patients most likely to be ER-negative first.
2. **Quality assurance (quality check):** after IHC is reported, the same score flags confidently discordant results for a pathologist's second review.

Development used TCGA-BRCA; external validation used CPTAC-BRCA. Both are publicly available (Genomic Data Commons, NCI Imaging Data Commons, cBioPortal).
